# **App Name**: España Quiz

## Core Features:

- Task Selection: Presents five buttons, each corresponding to a task.
- Question Display: Shows a question and its options from the selected task in a new screen.
- Answer Validation: Verifies the selected answer and shows whether it's correct or not.
- Correct Answer Display: If the answer is wrong, displays the correct answer.
- Automated Progression: Advances to the next question without repetition after a few seconds.
- Progress Tracking: Displays the progress of the quiz showing the total number of questions, correct answers, and incorrect answers.
- Summary of Errors: At the end of the task, shows a review of all the questions answered incorrectly.

## Style Guidelines:

- Primary color: Spanish Red (#DA291C) to evoke a sense of passion and national identity.
- Background color: Light beige (#F5F5DC), providing a soft and neutral backdrop.
- Accent color: Golden Yellow (#FFC107), complementing the red and adding vibrancy.
- Font: 'Inter', a sans-serif, for clear and modern readability on all devices.
- Use of simple, clean icons to represent the different tasks.
- Clean and intuitive design with clear task divisions and question layouts.
- Subtle transitions between questions and feedback states.
